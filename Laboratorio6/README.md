# Laboratorio 6 - Flujo MVT en Django

## Descripción del laboratorio 6
Aplicación web desarrollada con Django para demostrar el flujo completo del patrón MVT (Model, View, Template).
El proyecto implementa un catálogo de productos utilizando SQLite como base de datos.

##  Listado de funciones realizadas en laboratorio 6

- Listado de productos.
- Categorías de productos.
- Vista de detalle de cada producto.
- Estado de disponibilidad según stock.
- Enlaces entre la lista y el detalle.
- Filtro de productos por categoría.
- Datos de ejemplo cargados mediante un comando personalizado.
